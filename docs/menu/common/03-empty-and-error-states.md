# 공통 — 빈 상태·에러 상태 (U-4)

## 빈 상태

| 상황 | 요구사항 |
|------|----------|
| **데이터 없음** | 테이블·카드에 데이터가 0건일 때 "보유 포지션이 없습니다.", "아직 대화가 없습니다." 등 안내 문구. |
| **유도** | 가능하면 "새 대화", "연동 설정하기" 등 다음 액션 버튼 제공. |

## 에러 상태

| 상황 | 요구사항 |
|------|----------|
| **연결 실패** | API·에이전트 연결 실패 시 "연결에 실패했습니다.", "포트폴리오를 불러올 수 없습니다." 등 메시지. |
| **재시도** | 새로고침 버튼 또는 "다시 시도" 버튼 노출. |
| **일관성** | 각 탭·섹션에서 에러 시 동일한 톤(색상·아이콘) 사용. |
