# 공통 — 새로고침·반응형 (U-2, U-3)

## 새로고침 (U-2)

| 항목 | 내용 |
|------|------|
| **전역** | 헤더 "새로고침" 버튼으로 전역 또는 현재 탭 데이터 다시 불러오기. |
| **섹션별** | 각 섹션(대시보드 카드·모니터 테이블·KG 뷰어 등)에 "새로고침" 버튼 제공 시 해당 API만 재호출. |

## 반응형 (U-3)

| 항목 | 내용 |
|------|------|
| **대상** | 데스크톱·태블릿·모바일에서 레이아웃 적응. |
| **수단** | 미디어 쿼리(예: 768px, 1024px). 세션 목록은 데스크톱 사이드바 → 모바일 드로어/드롭다운 등. |
| **원칙** | 한 번에 하나의 컨텍스트에 집중하는 "앱다운" 체감. |
