# 공통 — 디자인 톤 (U-5)

## 일관된 톤

| 항목 | 내용 |
|------|------|
| **테마** | 다크 테마. 기존 DB 뷰어·트레이딩 대시보드 참고 톤 유지. |
| **카드** | 카드형 레이아웃, 둥근 모서리, 얕은 그림자. |
| **pill·배지** | 상태 표시(완료/오류/연결됨)는 pill 또는 배지로 통일. |
| **타이틀·색상** | 섹션 타이틀·강조 색상은 공통 CSS 변수로 정의해 전 앱에서 일관되게 사용. |

참고: [ui-design-trading-dashboard.md](../../ui-design-trading-dashboard.md), [nanoquant-v2-full-cycle-plan.md](../../nanoquant-v2-full-cycle-plan.md) 비주얼 가이드.
