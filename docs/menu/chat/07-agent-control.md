# AI 채팅 — 에이전트 제어·소통 (C-1~C-7)

사용자가 지시를 내리고, 필요 시 승인하고, 결과를 확인하는 흐름을 UI로 지원.

## 기능 목록

| 번호 | UI 기능 | 설명 | 대응 요소 |
|------|---------|------|-----------|
| C-1 | **자연어 지시 입력** | 채팅 입력창으로 지시 문장 입력·전송 | 메시지 입력 + 전송 버튼 |
| C-2 | **대화 히스토리** | 세션별 사용자·에이전트 메시지 이력 표시 | 채팅 탭 메시지 로그 영역 |
| C-3 | **스킬 호출 투명성** | 어떤 스킬이 호출됐는지, 인자·결과 요약 노출 | 메시지별 "사용된 도구/스킬" 배지·펼치기 |
| C-4 | **Reflection 상태** | 재시도·성공/실패 등 Reflection 결과 표시 | 메시지 영역 "Reflection: OK / Retry" 등 문구 |
| C-5 | **HITL 승인/거절** | HITL 필요 시 "실행 허용", "취소" 등 버튼으로 응답 | 채팅 메시지 하단 HITL 버튼 |
| C-6 | **로딩·단계 표시** | 응답 대기 중 "Thinking… / Acting…" 등 ReAct 단계 표시 | 채팅 영역 로딩/스피너 |
| C-7 | **에러·재시도** | 스킬 실패 시 에러 메시지 + 재시도 유도 | 채팅 에러 메시지, (선택) 재시도 버튼 |
| C-8 | **우측 스킬·도구 패널** | 사용 가능한 스킬·도구 목록을 **우측 사이드바**에 표시. **클릭** 시 이번 질의에 해당 스킬을 **강제 사용**하도록 요청(ReAct에 힌트 전달). **호버** 시 스킬/도구의 **상세 설명·파라미터**를 **툴팁**으로 제공. | 우측 "스킬 & 도구" 패널, 스킬 항목(이름·요약), 선택 시 배지/강조, 전송 시 `force_skill` 포함. |

## 상태·예외 (기획서 2.4)

- **로딩**: 채팅 응답 대기 시 스피너 또는 "Thinking… / Acting…" 등 ReAct 단계 표시.
- **에러**: 도구/스킬 실패 시 채팅에 에러 메시지 + "재시도" 옵션.
- **HITL 대기**: 사용자 응답 전까지 다음 Execution 블록 대기, 타임아웃 시 "취소됨" 처리.
