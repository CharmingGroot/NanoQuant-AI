# AI 채팅 — 세션 목록 UI

## 목록 항목별 디테일

| 항목 | 요구사항 |
|------|----------|
| **표시 내용** | 세션 제목(한 줄, 말줄임), 수정 시각(예: "2분 전", "오늘 15:30") 또는 `updated_at` 포맷. |
| **선택 상태** | 현재 열린 세션은 시각적으로 강조(배경색·테두리·굵은 글씨 등). |
| **호버/접근** | 항목 호버 시 삭제 버튼(휴지통 아이콘) 노출. 모바일은 길게 누르기 메뉴에서 "삭제"·"제목 수정" 제공 가능. |
| **제목 수정 진입** | 항목 더블클릭, 또는 항목별 메뉴(⋯) → "제목 수정" 선택 시 인라인 편집 또는 모달로 제목 입력란 표시. |
| **빈 목록** | 세션이 0개일 때 "아직 대화가 없습니다." + "새 대화" 버튼만 표시. |

## 레이아웃·반응형

| 구분 | 요구사항 |
|------|----------|
| **가시성** | 세션 목록이 채팅 화면에서 **기본으로 노출**된다. (세션 0개일 때는 빈 상태 + "새 채팅" 유도) |
| **데스크톱** | **제미니형 3단 레이아웃**: 좌측 = 세션 목록(새 채팅 버튼 + "채팅" 섹션 아래 세션이 쭉 나열), 중앙 = 채팅·입력, 우측 = 스킬·도구 목록. 세션 목록 = 좌측 사이드바(접기/펼치기 권장). |
| **태블릿/모바일** | 세션 목록 = 드로어(슬라이드) 또는 상단 드롭다운으로 열고, 채팅은 전체 너비. |
| **반응형** | 화면 크기에 따라 레이아웃 전환. 한 번에 하나의 컨텍스트(목록 vs 대화)에 집중하는 "앱다운" 체감. |
| **입력 영역** | 채팅 입력창은 하단 고정 또는 스크롤 시에도 접근 가능. |
| **빈/에러 상태** | 세션 없음·로딩·API 실패 시 안내 문구·재시도 노출. |

## 사용자 스토리 (참고)

- **US-1** 데스크톱에서 이전 대화 목록을 한눈에 보고, 좌측 세션 목록에서 클릭해 전환.
- **US-2** 모바일에서 세션 목록을 버튼/메뉴로 열면 드로어·드롭다운으로 목록 표시, 선택 시 해당 세션 채팅 전체 화면.
- **US-3** "새 대화" 버튼 클릭 시 새 세션 생성, 입력창 포커스.
- **US-4** 세션 항목 삭제 버튼/아이콘으로 확인 후 삭제.
- **US-5** 화면 크기 변경·모바일 접속 시에도 레이아웃 유지, 세션 목록·채팅·입력 영역 접근 가능.
