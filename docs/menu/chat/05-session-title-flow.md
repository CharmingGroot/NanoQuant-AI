# AI 채팅 — 세션 제목 (자동·수정 플로우)

## 제목 결정 규칙 (자동)

| 상황 | 제목 |
|------|------|
| 세션 생성 직후 | "새 대화" |
| 해당 세션에서 첫 사용자 메시지 전송 후 | 해당 내용 앞 N자(예: 50자) 또는 요약을 제목으로 서버에 반영. | 기존 `append` 시 `title` 갱신 로직 활용. |

## 제목 수정 플로우 (사용자)

| 단계 | 동작 | 비고 |
|------|------|------|
| 1. **수정 트리거** | 세션 항목 **더블클릭**, 또는 항목 메뉴(⋯) → "제목 수정". 또는 채팅 영역 상단(헤더) 현재 세션 제목 클릭. | |
| 2. **편집 UI** | **인라인**: 목록 항목이 입력란으로 전환, 기존 제목 채움. **또는** 모달/팝오버에 제목 입력 필드(최대 120자), "취소"·"저장" 버튼. | 한 줄 입력, 앞뒤 공백 trim. |
| 3. **저장** | "저장" 또는 Enter 시 `PATCH /agent/sessions/:id` body `{ "title": "새 제목" }` 호출. 빈 문자열이면 "새 대화" 등 기본값으로 저장. | API 확장 필요: 제목 수정 엔드포인트. |
| 4. **성공 시** | 목록·헤더에 새 제목 즉시 반영. 인라인이면 일반 항목 표시로 복귀. | |
| 5. **취소** | "취소" 또는 Esc 시 편집 취소, 기존 제목 유지. | |
| 6. **실패 시** | 400(길이 초과 등)·404·500 시 "제목 수정에 실패했습니다." 표시, 편집 상태 유지해 재입력 가능. | |
