# AI 채팅 — 개요

## 역할

사용자가 **자연어로 지시**를 내리고, 에이전트(ReAct)가 스킬을 실행한 뒤 **결과**를 돌려주며, **HITL**이 필요할 때만 승인/거절하는 흐름을 담는 메뉴. 세션별로 대화가 구분된다.

| 항목 | 내용 |
|------|------|
| **목적** | 지시 입력 → ReAct 실행 → 결과·스킬 호출 투명성·HITL 처리. |
| **위치** | 네비 "AI 채팅" (또는 "채팅"). |
| **레이아웃** | **제미니형**: 좌측 세션 목록(쭉 나열) · 중앙 채팅·입력 · 우측 스킬·도구 목록. |
| **핵심** | 세션 목록·새 채팅·전환·삭제·제목 수정 + 메시지 입력·히스토리 + **우측 스킬/도구 패널**(클릭 시 이번 질의에 해당 스킬 강제 사용, 호버 시 상세 툴팁) · 로딩·에러. |
