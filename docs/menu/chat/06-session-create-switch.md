# AI 채팅 — 새 세션 생성·전환

## 새 세션 생성

| 단계 | 동작 |
|------|------|
| **트리거** | "새 대화" 버튼 클릭. |
| **API** | `POST /agent/sessions` (body에 `title` 생략 가능). |
| **후처리** | 응답 `session_id`로 로컬 상태를 해당 세션으로 전환, 채팅 영역 비우기, 입력창 포커스. |

## 세션 전환

| 단계 | 동작 |
|------|------|
| **트리거** | 목록에서 다른 세션 클릭. |
| **데이터** | `GET /agent/sessions/:id`로 히스토리 조회. (이미 캐시돼 있으면 생략 가능) |
| **표시** | 채팅 영역에 해당 세션 메시지만 표시, 현재 세션 ID 갱신. |
