# 대시보드 — 개요

## 역할

메인 진입 시 **현재 포트폴리오**와 에이전트·서비스 상태를 한 화면에서 파악하는 요약 화면이다. 퀀트 에이전트 모니터링·통합 관리의 홈 역할.

| 항목 | 내용 |
|------|------|
| **목적** | 현재 보유 자산(포트폴리오)·수익 현황·에이전트/스킬 상태·최근 활동을 한눈에 표시. |
| **위치** | 앱 네비게이션의 첫 탭(또는 홈). `대시보드 | 채팅 | 백테스트 | 모니터 | 지식그래프 | 설정` 중 "대시보드". |
| **데이터** | 포트폴리오는 기존 DB·시뮬레이션·스킬 결과와 연동. 없을 경우 빈 상태·연동 유도 메시지. |
