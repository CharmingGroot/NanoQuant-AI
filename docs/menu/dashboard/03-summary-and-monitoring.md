# 대시보드 — 요약·모니터링 섹션

대시보드에 함께 노출하는 에이전트·서비스 상태 요약. 실시간 모니터링(M-1~M-4, D-1)에 대응.

## 섹션별 내용

| 섹션 | 내용 | 비고 |
|------|------|------|
| **연결 상태** | API/에이전트 연결 여부(예: 연결됨/끊김). | M-1. 요약 카드 또는 헤더 |
| **스킬 연결** | 등록된 스킬 목록·상태(가용/에러). | M-2, G-2. 테이블 또는 리스트 |
| **활성 세션** | 현재 세션 수, 최근 활동 시각. | M-4. 카드 또는 숫자 |
| **최근 결정** | 에이전트가 최근 실행한 스킬·세션·결과 요약·시각. | D-1. 테이블, 상세는 모니터 탭으로 |

## 데이터 소스

- **연결 상태**: `GET /agent/health`
- **스킬**: `GET /agent/skills`
- **세션 수**: `GET /agent/sessions` 응답 배열 길이 (또는 전용 메타 API)
- **최근 결정**: `GET /agent/kg/recent?limit=N`

## 요약

- 대시보드 = **현재 포트폴리오**(총자산·현금·포지션·손익) + **에이전트 상태**(연결·스킬·세션·최근 결정).
- 상단 요약 카드 + 하단 "현재 포트폴리오" 테이블 구조로 일관된 톤(다크 테마·카드) 유지.
