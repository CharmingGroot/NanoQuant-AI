# 모니터 — 개요

## 역할

에이전트가 **실시간으로** 어떤 스킬을 실행했는지, 성공/실패·결과 요약을 **시간순**으로 보여 주는 탭. 대시보드의 "최근 결정"보다 더 많은 이력·상태를 다룬다.

| 항목 | 내용 |
|------|------|
| **목적** | 실시간 활동 스트림(M-5). 스킬 실행·에러·HITL 대기 등이 시간순으로 노출. |
| **위치** | 네비 "모니터". |
| **데이터** | `GET /agent/kg/recent?limit=20` (또는 더 큰 limit). D-2 실시간 활동 목록. |
