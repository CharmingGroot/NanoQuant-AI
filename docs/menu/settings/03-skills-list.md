# 설정 — 스킬·도구 목록 조회

## 요구사항 (G-2)

| 항목 | 내용 |
|------|------|
| **목적** | 등록된 스킬 이름, 설명, 파라미터, HITL 여부를 테이블 또는 리스트로 표시. |
| **API** | `GET /agent/skills` — 응답: `{ skills: [{ name, description, params_schema }], hitl_skills: string[] }`. |
| **UI** | 설정 탭에 스킬 테이블. 컬럼: 이름, 설명, 파라미터(또는 스키마 요약), HITL 여부. 대시보드 "스킬 연결" 테이블과 동일 데이터 소스. |
