# 설정 — LLM API 키·모델

## 요구사항 (G-1)

| 항목 | 내용 |
|------|------|
| **목적** | 에이전트 채팅 사용을 위한 LLM API 키 입력. |
| **입력** | 제공자(Claude/OpenAI)·키·모델 선택 후 저장. |
| **저장** | 클라이언트 **localStorage**. 서버에는 저장하지 않음. |
| **사용** | 채팅 요청 시 본문에 키를 실어 보내고, 서버는 해당 요청에만 사용. |

## UI

- 폼: 제공자 선택, API 키 입력란, 모델 선택(선택), "저장" 버튼.
- 저장 후 채팅 탭에서 에이전트 호출 시 해당 키가 body에 포함되도록 연동.
